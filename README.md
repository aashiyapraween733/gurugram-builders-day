# Gurugram Builders Day 2026

A one-page website for **Gurugram Builders Day**, a free community build day for students and early-career developers in Gurugram, India. The event is on Saturday, 24 October 2026.

## What's inside

- `index.html`: the whole site, written in plain HTML and CSS with no build step
- Sections for the event overview, schedule, venue and directions, FAQ, and an RSVP form (demo only, no backend yet)
- Responsive layout that supports dark mode

## Run it locally

Open `index.html` in any browser.

## Deploy

Import this repository into [Vercel](https://vercel.com/new). Vercel detects the static site automatically, so no settings are needed.
